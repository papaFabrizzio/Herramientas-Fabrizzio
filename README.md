# Librería de Utilidades 5to Bachillerato
[cite_start]Esta librería es un conjunto de herramientas reutilizables para validación de datos, cálculos matemáticos y procesamiento de texto[cite: 6, 8].

## Funciones principales
- [cite_start]**Validaciones:** Email, Carné, Fechas y DPI guatemalteco[cite: 29, 36, 39, 41].
- [cite_start]**Matemáticas:** IMC, Factorial, Primos, Descuentos y Promedios[cite: 30, 33, 34, 37, 39].
- [cite_start]**Conversiones:** Moneda (Q/$), Temperatura (C/F)[cite: 31, 35].

## Uso
Importa el módulo y llama a la función deseada:
`from utilidades import calcular_imc`
